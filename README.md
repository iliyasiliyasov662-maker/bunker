# Бункер — 3D-игра для друзей в браузере

Катастрофа, бункер и мест на всех не хватает. Каждый раунд вы открываете по карте, спорите и голосуете, кого выгнать. В конце игра проигрывает, как прошли годы в бункере, и разбирает ваш выбор: кого правильно выгнали, кого зря и каким был идеальный состав.

## Что внутри

- 3D-комната с небольшим столом: все сидят близко, у всех противогазы вместо лиц. Мышкой крутишь головой, и остальные видят, куда ты смотришь.
- Свои руки в кадре от первого лица, они двигаются при жестах.
- Жесты на клавишах 1–9: кивнуть, помотать головой, развести руками, показать, поднять руку, фейспалм, ржать, задуматься и средний палец.
- **T** — кинуть помидор в того, на кого смотришь (в центре экрана прицел с именем). Остаётся пятно на противогазе, а у того, в кого попали, экран заляпан.
- **F** — подзатыльник соседу слева или справа.
- Удобно и с телефона: голову крутишь пальцем, внизу панель с кнопками «Карты», «Игроки», «Бункер», «Чат», «Жесты», «Кинуть» и «Шлёп». Когда твой ход или голосование, нужное окно открывается само.
- 8 карт у каждого: профессия (со стажем), биология, здоровье, хобби, фобия, багаж, факт, минус. В колодах сотни карт, много современных приколов.
- 16 катастроф и 24 скрытые проблемы бункера. На 3-м раунде одну проблему объявляют по радио.
- Козырь у каждого игрока: иммунитет, разоблачение, подглядеть карту, двойной голос и другие.
- Режим «Снаружи»: выгнанные получают по два действия (раскрыть чужой секрет, заглушить чей-то голос, подбросить припасы, пустить слух, сломать оборудование).
- Набор карт 18+ включается галочкой в лобби.
- Финал: история бункера, вердикт и разбор выбора по каждому игроку. Отдельно отмечается, в кого прилетело больше всех помидоров.

## Правила коротко

- Игроков 2–8, лучше 5–6. В бункер попадает половина (5 игроков — 3 места, 6 — 3 места).
- 5 раундов. В свой ход открываешь одну карту и рассказываешь, почему ты нужен. В первом раунде все открывают профессию.
- После некоторых раундов — голосование. Ничья: переголосование, снова ничья — жребий.
- Выгнанный открывает все карты.
- Ведущий (создатель комнаты) переключает фазы и может пропустить ход того, кто отошёл.

## Запуск у себя

Нужен только Node.js 18 или новее, никаких библиотек ставить не нужно.

```
node server.js
```

Открой `http://localhost:3000`. Чтобы потестировать одному, открой игру в двух вкладках (вторую в режиме инкогнито).

## Как играть с друзьями по сети

Сервер должен быть доступен из интернета. Проще всего бесплатный хостинг Render:

1. Создай репозиторий на GitHub и загрузи туда все файлы этой папки.
2. Зайди на render.com, создай **Web Service** и подключи этот репозиторий.
3. Build Command оставь пустым (или `npm install`), Start Command: `npm start`, тариф Free.
4. Через пару минут Render выдаст адрес вида `https://твоя-игра.onrender.com`. Создай комнату и скинь друзьям ссылку из лобби.

Бесплатный сервер засыпает, если в него долго никто не заходит, и первое открытие может занять около минуты. Комнаты хранятся в памяти, поэтому после перезапуска сервера нужно создать новую комнату.

Общаться голосом удобнее всего в Discord, а в игре есть текстовый чат.

## Как добавить свои карты

Все карты лежат в `cards.js`. Одна строка — одна карта:

```
Текст карты | навыки через запятую | смешная строчка для финала
```

- Навыки решают проблемы бункера: `med food water repair electric defense science morale leader tech build hunt chem rescue lang`.
- Плохие метки: `danger thief glutton conflict lazy contagious dying terminal infertile weak`.
- `-med` отнимает навык (например, фобия «боязнь крови» отключает медицину).
- `{мужской|женский}` подставляет окончание по полу персонажа: `Служил{|а} в армии`.
- В строчке для финала `{name}` заменяется на имя игрока.

## Файлы

- `server.js` — сервер: страница, комнаты, обновления в реальном времени.
- `game.js` — правила, голосование, финал и разбор выбора.
- `cards.js` — все колоды.
- `public/` — то, что видит игрок: интерфейс (`app.js`) и 3D-сцена на Three.js (`scene.js`).
