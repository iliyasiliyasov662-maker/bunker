# Avalon — онлайн-игра для друзей

Браузерная версия настольной игры в скрытые роли «Авалон» для 5–10 игроков.
Сервер не нужен: сайт выкладывается на GitHub Pages, игроки соединяются друг с другом напрямую (WebRTC через PeerJS).

## Как выложить на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите туда **содержимое** этой папки: `index.html`, `css/`, `js/` и остальное.
2. Откройте **Settings → Pages**.
3. В **Source** выберите `Deploy from a branch`, ветку `main`, папку `/ (root)` и нажмите **Save**.
4. Через минуту игра откроется по адресу `https://<ваш-ник>.github.io/<репозиторий>/`.

## Как играть

1. Один игрок (хост) вводит имя и нажимает **«Создать комнату»**.
2. Хост жмёт **«Скопировать ссылку-приглашение»** и отправляет ссылку друзьям. Можно просто продиктовать 5-значный код.
3. Друзья открывают ссылку, вводят имя и заходят в комнату.
4. Хост настраивает роли и нажимает **«Начать игру»**. Если людей меньше 5, места можно заполнить ботами.
5. Голос — в Discord или Telegram, всё остальное (карты, голосования, походы, чат) — в игре.

Ещё есть режим **«Потренироваться с ботами»**: он работает полностью офлайн.

## Что реализовано

- Полные правила: составы на 5–10 игроков, размеры походов, два «Провала» в 4-м походе при 7+ игроках, 5 отклонённых составов подряд, убийство Мерлина.
- Роли: Мерлин, Персиваль, Верный слуга Артура, Убийца, Моргана, Мордред, Оберон, Приспешник Мордреда.
- Владычица Озера.
- Тайная раздача ролей: каждый браузер получает только то, что положено видеть его роли.
- Анимации раскрытия ролей, голосований и карт похода, звуки (их можно выключить).
- Таблица всех голосований, журнал игры, чат.
- Переподключение: если обновить страницу или пропадёт интернет, игрок возвращается за стол со своей ролью. Хост тоже может обновить страницу: игра сохраняется.
- Если кто-то выпал, хост может посадить вместо него бота (Меню → «Заменить ботом»).
- Есть мобильная версия.

## Как это работает и ограничения

- Игру «держит» вкладка хоста. Пока партия идёт, хосту нельзя закрывать вкладку. Обновить страницу можно: комната восстановится.
- Для первого рукопожатия используется бесплатный публичный сервер PeerJS (`0.peerjs.com`), дальше данные идут напрямую между браузерами.
  Если в какой-то сети соединение не проходит, PeerJS автоматически переключается на свои TURN-серверы.
- Хост технически может подсмотреть роли через инструменты разработчика браузера. Это игра для друзей, поэтому играем честно.
- При желании можно поднять свой сигнальный сервер (`npx peer --port 9000`) и указать его в `index.html` перед подключением скриптов:
  ```html
  <script>window.AVALON_PEER_SERVER = { host: 'my-server.example.com', port: 443, path: '/', secure: true };</script>
  ```

## Структура

```
index.html          страница
css/style.css       оформление
js/engine.js        правила игры (чистая логика, без интерфейса)
js/bots.js          боты
js/art.js           вся графика (SVG-карты ролей, жетоны, аватары)
js/net.js           сеть (PeerJS)
js/sound.js         звуки (WebAudio, без файлов)
js/app.js           интерфейс, логика хоста и клиента
js/vendor/          PeerJS 1.5.4 (MIT)
test/sim.js         автотест: 3000 партий ботами (`node test/sim.js`)
```

Шрифты: Cinzel Decorative, Cormorant Garamond, Inter (Google Fonts).
